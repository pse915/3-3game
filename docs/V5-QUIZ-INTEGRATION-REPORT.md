# 미래 다이어리 v5 — 저출산·고령사회 학습 퀴즈 통합 및 QA 보고서

## 기준 및 실행
- 원본: `서라벌여중-미래다이어리-v4-멈춤버그-수정판.zip`.
- 실행: `pip install -r requirements.txt` 후 `streamlit run app.py`.
- 기존 프로젝트의 8개 메인 챕터, 32개 사건과 11개 분기 변형을 수정하거나 삭제하지 않았음. 기존 이미지 에셋과 마을·학교 맵은 그대로 사용.
- 교사 표시 이름 `기술썜` 유지.

## 실제 추가한 기능
1. **사건 완료 이후 필수 퀴즈 12개**: 관련 스토리를 체험한 뒤 그 사건에 연결된 퀴즈가 `스토리`를 통해 열림. 보충 퀴즈 3개는 56세 이후 `메뉴 → 미래 사회 퀴즈 학습장`에서 선택 가능.
2. **문제-선택-확인-피드백**: 정답 해설, 오답 힌트 및 누적 시도 횟수, 3회 이상 오답 시 개념 다시 살펴보기, 원하는 횟수만큼 재도전. 오답은 개인 지표·자금에 벌점을 부여하지 않음.
3. **화면 연출 → 선택 → 지속되는 마을 변화**: 정답 시 개선 전/후 픽셀 시설 비교 그림과 주민의 고민을 보여주고, 학생이 `마을에 개선안을 적용하기`를 직접 선택할 때에만 사회 지표와 실제 마을 지도에 변화를 기록함. 마을에 적용한 시설은 표식으로 표시되며 근처에서 시설 이야기를 볼 수 있음. 출입구로부터 떨어진 통행 가능한 타일에 배치하여 이동을 방해하지 않도록 설계.
4. **학습 다이어리**: 완료한 지식 주제, 학습한 내용과 마을에 실제 적용했는지 여부를 표시하고 65세 회고와 텍스트 결과에 연결.
5. **저장 호환성**: 기존 v3/v4 키와 내 인생 스토리의 `version: 4` 포맷 유지. 선택적으로 `life.story.quiz` 객체를 추가. 현재 문제 ID, 정답 완료 ID, 오답 시도, 힌트 확인, 정책 적용 내역 저장. Python 서버의 유효성 검사를 함께 확장. 기존 v4 완료 기록을 강제로 퀴즈 미완료 상태로 되돌리지 않음.
6. **진행 정지 방지**: 퀴즈 대기 상태를 별도 저장. 오답 재시도에서 스토리 재귀 호출 없음. 이미 끝난 문제 반복 요청·정책 중복 적용 차단. 잘못된 문제 ID에 대한 복구 버튼 제공. 모달 종료 후 `스토리`를 누르면 현재 문제를 이어서 풀 수 있음.

## 실제 수행하지 못한 검증과 제한

- **브라우저 E2E 미검증**: Chromium을 구동했지만 `http://127.0.0.1:8765/?test` 접속이 `net::ERR_BLOCKED_BY_ADMINISTRATOR`로 거절되었음. 실제 퀴즈 버튼 클릭 및 렌더링 검증을 했다고 주장하지 않음.
- **실물 태블릿 미검증**: 방향패드와 선택지 터치 중첩, 화면 회전 및 장시간 플레이는 운영 기기로 별도 확인 필요.
- **Google Sheets 실전송 미검증**: 연결 계정이 없어서 라이브 전송 확인 불가. 기존 코드와 저장 형식을 보존하고 SQLite 검증 수행.
- **20분 수업 운영 미검증**: 문항 수와 화면 흐름을 수업 시간에 맞추되 실제 학생들의 평균 소요 시간은 수업에서 확인 필요.
- 정책과 마을 변화는 **교육용 가상 모델**이며 실제 인구 예측이 아님. 퀴즈 정답 자체는 정책 결과를 자동 상승시키지 않음.
