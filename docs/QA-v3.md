## 이번에 실행한 검증

- `npm test`: JavaScript 19개 통과. 기존 243개 핵심 선택 조합과 80개 맵 출입구·NPC·기존 상호작용 도달성, 화장실 소품, 자유 순서·후속 잠금·자원 경계·사건 중복·하루 반복·8가지 결과 조건 확인.
- `python -m unittest discover -s tests -p "test*.py"`: Python 11개 통과. 인증·revision·복원·재시도 및 확장 상태·모의 Sheets 중복/압축/손상 폴백 검증.
- `tests/browser_v3.cjs`: Windows Chrome에서 기존 핵심5선택→학교귀환→성찰→엔딩→새로고침 이어하기. 런타임 오류0. 주요 학교·마을 실내 화면 캡처.
- `tests/expanded_browser.cjs`: Chrome 터치 에뮬레이션에서 실제 UI로 주거→후속 공동주거→직업 작업대→돌발사건→이유·미래 계획→오프라인 저장→새로고침 복원→집에서 다음 날. 두 손가락 입력, 1024×768과768×1024, 주요 버튼의 화면 내부 배치 확인.
- `tests/streamlit_v3.cjs`: 실제 Streamlit iframe 안에서 시작·자유 활동·기기 저장과 서버 저장 응답 확인. 실제 Google Sheets는 연결하지 않음.
- `tests/performance_v3.cjs`: Windows Chrome 1024×768, CPU4배 제한, 마을에서24초 이동 입력, 6초 간격4표본 약59.24~59.92FPS, 맵캐시2개. 실제태블릿·장시간 메모리 안정성 보장 자료가 아님.

현재 결과 JSON은 `docs/evidence/v3-*`, 현재 캡처는 `docs/screenshots-v3/`에 있다. 자동 플레이에는 localhost에서만 활성화되는 좌표 이동용 검증 API가 일부 사용된다. 선택·성찰·메뉴·직업 작업·사건 해결은 실제 UI 입력으로 진행했다.

## 남은 요구사항과 정확한 제한

1. 실제 학교 외관·층별 자료와의 정밀 대조, 학습지원실2를 기준으로 한 회전 방향 확인, 모든 교실의 실측 일치 여부는 추가 자료가 필요하다.
2. iPadOS Safari·Android Chrome의 실제 학교 태블릿, 장시간 배터리·메모리, 학생20분 수업 시간은 실기기/사용자 검증이 필요하다.
3. WebKit 자동 검증은 설치 후에도 필수 라이브러리 누락으로 실행되지 않았다. 기존v2 WebKit 통과 자료를 이번 통과로 재사용하지 않는다.
4. 핵심 그래픽 전체의 전면 교체, 모든NPC의4방향 걷기·상호작용·표정, 각지구5발견·시설3상호작용 수치와 충분한 콘텐츠 밀도는 아직 전체 조건을 충족하지 않는다.
5. 풍부한 독립 직업 게임 수준의 확장, 날씨·계절·배경음·표정 대화·완전한 하루 일과는 미구현이다. 게임은 기본적으로 무음이다.
6. 기존 핵심5이야기는 진행 안내를 위해 순서를 유지한다. 자유25활동과 후속 기회가 비선형인 구조이며 핵심 이야기 전체가 완전히 분기하는 구조는 아니다.
7. 가방은 체험 배지·열린 기회·학교 방문과 발견한 다이어리 조각8개의 기록이다. 거래 가능한 물건 인벤토리는 미구현이다.
8. Sheets 실서비스, GitHub 업로드 및 운영 배포는 수행하지 않았다. ZIP에는 비밀키·학생 기록·실행 중 생성된 데이터베이스를 넣지 않는다.

완료된 기능과 부분 구현을 구분한 실행 가능한 고도화 수정판이다. 학교 구조 정확성·에셋 최종 미적 인수·학생 수업 검증을 거치기 전 최종10/10 완성본으로 표시하지 않는다.
