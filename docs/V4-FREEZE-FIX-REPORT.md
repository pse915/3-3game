# 미래 다이어리 v4 — 멈춤·무응답 방지 수정 보고서

## 기준 파일

`서라벌여중-미래다이어리-v4-한글화-디버깅완료.zip`을 직접 수정하였다. 15~65세 8개 챕터, 기존 사건·대사·에셋, 로컬/서버 저장 스키마를 보존하였다.

## 확인한 멈춤 및 진행 불가 위험

| 위험 지점 | 기존 원인 | 적용한 조치 |
| --- | --- | --- |
| 스토리 화면 재귀 호출로 진행 정지 | `storyPanel`에서 이벤트가 없으면 `storyEnding` 호출, 엔딩 미완성 상태에서는 `storyPanel`을 다시 호출하여 무한 재귀할 수 있음 | 무한 재귀 차단. 완료 기록의 사건 ID를 바탕으로 다음 미완료 장면을 찾는 복구 화면과 버튼 제공. 현재 사건 ID가 이미 기록에 존재할 때도 복구 가능 |
| 화면 그리기 오류 발생 후 영구 멈춤 | `requestAnimationFrame`의 콜백에서 예외가 발생하면 다음 프레임 예약까지 실행되지 않음 | 프레임 예외 복구 가드 추가. 반복 예외 시 진행 기록을 유지한 채 시작 화면으로 안전 복귀, '이어서 걷기' 안내 |
| 지도 이동 중 무응답 | 지도 `fetch`에 시간 제한이 없고 `loadMap`이 로딩 중 중복 호출을 조용히 무시함 | 지도 요청에 12초 시간 제한과 실패 안내를 추가하고, 겹친 지도 이동은 순서대로 처리. 이동 실패 시 이전 맵을 유지 |
| 시작 시 지도 로딩 오류로 빈 게임 화면 | `loadMap` 실패 후에도 시작 화면을 숨기고 게임을 시작함 | 지도 로딩 성공을 확인한 뒤에만 시작 화면 숨김. 실패 시 다시 시도 가능 |
| 오래된 저장 좌표에서 캐릭터 움직임 불가 | 저장 위치가 벽이나 접근 불가 칸일 때 주변 9칸 검색 실패 후 그대로 등장 | 이동 가능한 주변 타일·기본 등장 위치·전체 맵 순으로 안전한 등장 위치를 찾도록 변경 |
| 큰 맵에서 프레임 저하 | 마을의 모든 건물을 매 프레임 순회·필터링하고 미니맵 배경을 반복 그림 | 타일 청크 기반 공간 인덱스, 보이는 건물만 처리, 미니맵 기본 그림 캐시 |
| 안내 경로 반복 계산 | 목적지 경로가 없으면 매 400ms마다 같은 경로 탐색 재수행 가능 | 도달 불가 경로를 출발/도착 타일별로 5초간 기억하되, 강제 갱신/위치 이동 시 재탐색 |
| 저장·서버 통신으로 인한 반복 갱신 | 게임 루프가 7초마다 `save(false)`로 리비전을 증가시켜 Streamlit 컴포넌트가 불필요하게 서버 저장을 반복할 수 있음 | 20초 주기 로컬 자동 백업은 리비전을 증가시키지 않음. 사용자 선택·수동 저장은 기존처럼 리비전 및 서버 저장 반영 |
| 추가 장애 위치를 알기 어려움 | 화면 렌더링·비동기 예외가 발생해도 사용자에게 진단 자료가 없음 | UI/비동기/화면 오류 최근 20건을 인게임 진단 JSON으로 다운로드 가능(사용자 ID·토큰 제외) |

## 검증 결과

- JavaScript 구문 검사: 통과.
- Node 단위·회귀 검사: **38개 통과**. 공간 인덱스 결과 일치, 중단된 스토리의 32사건 위치 복구, 안전 좌표 계산, 기존 200개 이상의 생애 선택 경로 테스트 포함.
- Python/SQLite/서버 저장 테스트: **12개 통과**.
- 지도 유효성·스토리 연결·저장 상태 무결성: 관련 기존 테스트 통과.
- ZIP 무결성 및 원본 PNG 에셋 동일성: 배포 전 검사.

## 확인이 필요한 사항

- **실제 브라우저 조작**: 실행 환경의 Chromium/Playwright에서 로컬/파일/라우팅된 페이지까지 `ERR_BLOCKED_BY_ADMINISTRATOR`로 차단되었다. 게임 화면 실제 조작을 통한 재현·E2E 검사 **미완료**.
- **실물 태블릿**: 장시간 플레이·OS별 터치 조작 **미검증**.
- **Google Sheets 실전송**: 연결 계정이 없어 외부 서비스 실제 저장 **미검증**.
- 멈춤 발생 당시 사용자 화면과 정확한 조작 단계가 제공되지 않아 모든 기기별 멈춤 증상의 제거를 확언할 수 없다. 문제가 재발하면 게임 메뉴 → **문제 진단 기록 내려받기**로 생성된 JSON을 전달하면 구체적인 원인을 좁힐 수 있다.

## 실행

기존과 동일하다. `pip install -r requirements.txt` 후 `streamlit run app.py`.

게임을 이어서 시작하면 이전 `서라벌여중-미래다이어리-v4-한글화-디버깅완료.zip` 버전의 저장 데이터와 호환되며 데이터 마이그레이션이 필요하지 않다.
