## 작동 방식

1. **메인 목표**: 현재 `life.story` 상태와 다음 유효 이벤트 ID를 읽어서 현재 해야 할 한 가지 행동만 보여줍니다. 기존 퀘스트 진행을 덮어쓰지 않습니다.
2. **노란 별**: 이야기 이벤트가 현재 지도에 있으면 실제로 생성되는 스토리 NPC의 위치에, 다른 맵에 있으면 현재 지도에서 다음에 지나갈 실제 출입구에 표시합니다. 거리 계산 대상과 별표 위치가 일치합니다.
3. **길 안내**: 맵 통로 그래프 `connections.json`, 지도 `portals` 및 장애물 `solid`를 활용하며 현재 지도에서 목표에 접근 가능한 타일까지 경로를 계산합니다. 경로 계산은 렌더링 매 프레임이 아니라 목표와 캐릭터 위치가 변경될 때만 필요한 만큼 갱신합니다. 실패 시 버튼과 기존 스토리 접근 방법을 유지합니다.
4. **권장 버튼**: 이동/진행/정답 확인과 재도전 같은 **기능 버튼**만 강조합니다. 대학 진학·결혼·출산 등 삶의 선택지에는 정답/추천 표기를 하지 않습니다.
5. **단계적 도움**: 목표가 변하지 않고 게임을 조작할 수 있는 시간이 30초/60초/90초 경과할 때마다 힌트가 추가됩니다. 대화창/퀴즈/설정 화면, 비활성 탭, 지도 로딩 중에는 진행되지 않습니다.
6. **빠른 이동**: 현재 목표가 다른 맵에 있을 때, 학생이 요청한 경우 목적지 스폰으로 이동합니다. 90초 후 제공하는 `목표 근처로 이동`은 목표 NPC와 대화하기 쉬운 위치로 이동할 뿐 인생 선택이나 퀴즈 정답을 자동 처리하지 않습니다.
7. **저장 호환**: 기존 `version:2` 게임 데이터의 `life.settings.storyFocus` 선택 필드를 사용합니다. 기존 필수 키, 저장 파일 버전, 사건/선택 ID를 바꾸지 않았습니다. 초기값은 스토리 집중 모드입니다.

## 테스트 결과

- JavaScript 테스트: **60/60 통과** (`node --test tests/*.test.mjs`). 기존 테스트 53 + 길 안내 전용 7.
- Python/SQLite 저장 검사: **14/14 통과** (`python -m pytest -q tests`).
- 실제 `connections.json` 기반 핵심 스토리 장소 12곳의 서로 다른 출발/도착 조합 **132개에서 다음 이동 포털의 접근 가능한 경로 확인**.
- 200개 생애 선택 경로의 65세 완주, 러시아어 전환, 엔딩 상태 검증은 기존 자동 테스트를 함께 실행해 통과했습니다.
- 신규 경로 탐색은 충돌 타일, 연결되지 않은 통로, 범위 밖 목표를 입력받아 안전한 실패를 반환하도록 테스트했습니다.

## 검증 제한 및 수업 적용 전 권고

- Playwright Chromium 브라우저에서 실제 게임 URL을 열려고 시도했지만 이 환경은 `net::ERR_BLOCKED_BY_ADMINISTRATOR`로 로컬·모의 도메인에 대한 브라우저 탐색을 차단합니다. **실제 클릭·렌더링·터치 실기기 테스트는 완료하지 못했습니다.**
- 사용 환경에서 노란 별표 위치, 포털 진입, 설정 언어 전환 및 해상도별 UI를 직접 확인해야 합니다.
- Google Sheets 라이브 전송은 인증된 실제 서비스 환경에서 확인하지 못했습니다. 기존 연동 코드는 변경하지 않았습니다.
- 약 20분 수업 완주 시간은 자동 상태 검증과 별개로 실제 학생의 조작·읽기 속도에 따라 확인해야 합니다.

## 수업 현장 확인 순서

1. 한국어/러시아어 각각에서 새 게임 시작 → `★ 현재 목표` 확인.
2. 학교 스토리 NPC와 대화 → 다음 별표로 자동 이동되는지 확인.
3. `★ 길 안내` → 학교 출구/마을/교실 포털을 통한 실제 이동 확인.
4. 퀴즈에서 오답 후 재도전 → 정답 후 다음 사건 목표 전환 확인.
5. 설정의 스토리 집중/자유 탐험 전환 → 저장/새로고침 후 복원 확인.
6. 65세까지 진행 → 미래 마을·학교 비교 이미지와 러시아어 엔딩 확인.
