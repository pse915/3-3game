# 교과서와 게임 활동의 연결

분석 기준은 제공된 `교과서102-103페이지(5).docx`의 현재 내용이다. 102~103쪽의 중심 주제는 저출산·고령 사회와 가족 친화 문화이다. 일반적인 진로·경제 시뮬레이션 전체를 교과서 직접 내용이라고 표현하지 않는다.

| 확인한 교과서 개념 | 실제 게임 경험 | 돌아볼 질문 |
|---|---|---|
| 고용 불안정과 주거·양육 부담 | 핵심 첫 하루, 주거 상담, 생활비 선택 | 개인의 노력만으로 해결하기 어려운 조건은 무엇인가? |
| 일·가정 양립의 어려움 | 핵심 교대표, 자유 시간·직업 체험 | 일과 쉼, 돌봄 시간이 겹치면 어떻게 조정할까? |
| 출산·양육의 국가·사회 책임 | 핵심 돌봄 연결, 공공서비스 활동 | 도움을 한 사람에게 맡기지 않을 방법은 무엇인가? |
| 양성평등과 가족 친화 문화 | 공동주거 역할표, 돌봄 시간 나누기 | 성별 대신 동의와 가능한 시간을 기준으로 나눌 수 있을까? |
| 고령화와 돌봄·의료·생활안전 필요 | 의료·복지 체험, 핵심 마을 정책 | 서로 다른 연령의 주민에게 필요한 환경은 무엇인가? |
| 세대 간 이해와 협동 | 정원·공동체 활동, 관계와 후속 사건 | 함께 살아가는 데 필요한 약속은 무엇인가? |
| 노후 준비의 재무·건강·여가·대인관계 | 핵심 미래의 나, 저축·산책·취미·만남 | 네 영역을 조금씩 준비하려면 지금 할 수 있는 일은 무엇인가? |

직업별 작업 체험, 생활자금·가상 시간·피로, 8가지 미래 모습은 위 주제를 체험하기 위한 **게임 확장 모형**이다. 수치는 성적이나 실제 미래 예측이 아니다. 결혼·출산 여부와 특정 가족 형태를 성공의 조건으로 삼지 않는다.

자료의 과거 통계와 법률 설명은 교과서에 실린 당시 내용으로만 읽었으며, 현재 통계·정책이라고 재표시하지 않았다. 최신 통계 암기를 요구하는 퀴즈는 추가하지 않았다.

## 20분 수업 운영 제안

0~3분 학교 도입, 3~6분 일과 집, 6~12분 시간·돌봄·마을 선택, 12~16분 미래의 나와 선택 활동, 16~18분 학교 귀환과 다이어리, 18~20분 성찰 공유를 목표로 한다. 빠른 이동과 한 개의 다음 목표 안내를 제공한다. 이 시간표는 설계 제안이며 실제 학생의 20분 플레이 검증은 아직 하지 않았다. 선택 활동을 모두 완료할 필요가 없다.

자유 활동은 한 날의 480분이라는 **가상 시간**을 사용한다. 실제 수업 시간이 480분이라는 뜻이 아니다. 화면 읽기와 메뉴 체류를 포함한 실제 접속 플레이 시간은 별도로 기록된다.
