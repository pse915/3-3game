# 미래 다이어리 v5.1 — 한국어·러시아어 및 엔딩 지도 시각화 구현·검증 보고서

## 수정 범위

- v5 프로젝트의 기존 8개 생애 챕터(주요 사건 32개, 조건별 변형 11개) 및 학습 퀴즈 15개를 유지했습니다. 스토리와 퀴즈의 내부 ID, 정답, 점수 처리 및 기본 한국어 자료는 수정하지 않았습니다.
- `components/rpg_game/i18n.js`: 한국어/러시아어 번역 조회, 번역 자료 로딩, 게임 내 글자 노드의 실시간 변경·복원, 언어 설정 유지. 게임 설정과 타이틀의 `언어 / Язык` 및 대화·퀴즈 도중 전환 가능한 언어 버튼을 추가했습니다.
- `components/rpg_game/ru_story.json`, `ru_variants.json`: 모든 메인 사건, 선택지, 결과, 조건 분기 러시아어 번역.
- `components/rpg_game/ru_quiz.json`: 문제 15개, 보기, 힌트, 해설, 마을 개선안 및 정책 학습 개념 번역.
- `components/rpg_game/ru_explore.json`, `ru_context.json`, `ru_maps.json`, `ru_interface.json`: 기존 자유 탐험 퀘스트·활동, 맵·NPC·교사·장소 안내, 핵심 UI 및 스토리 보충 문장 번역. 저장된 문장 내 한국어는 화면 표시 단계에서 전환하므로 원본 저장 형식은 보존됩니다.
- `components/rpg_game/ending_visual.js`: 실제 기존 게임의 `town.json`/`school.json` 타일 데이터와 PNG 스프라이트를 사용해 960×540 크기의 마을/학교 이미지를 각각 15세·65세 시점으로 4개 생성합니다. 정책 적용 기록, 사회 지표에 따른 마을의 활기·적응·쇠퇴·심각한 쇠퇴, 학교의 세대통합 및 시설 활용 변화 등을 합성합니다. 동일한 촬영 구도로 전후 비교할 수 있습니다. 이미지에는 이름·개인정보를 합성하지 않으며, 1920×1080 PNG 1장으로 내려받을 수 있습니다.
- `components/rpg_game/game.js`, `index.html`, `style.css`: 설정/UI, 제목 언어 메뉴, 맵 내 NPC 텍스트 언어 전환, 65세 생애 결말 뒤 이미지 비교 화면, 원본 기록을 근거로 한 대표적 선택 표시, 오류시 재시도. 65세 이전에는 결과 잠금. 완성 후 다이어리에서 이미지를 다시 볼 수 있습니다.
- `components/rpg_game/story.js`: 저장 필드 `endingVisualization` 유효성 검사 및 구 저장 파일과의 호환성. 엔딩 이미지 상태에는 선택한 정책, 사회 지표, 후속 연출 분기가 기록됩니다. 언어 전환은 정답·세계 상태·관계·스토리 진행을 바꾸지 않습니다.

## 표시 원칙 및 기존 콘텐츠 보호

- 한국어가 초기 기본 언어입니다. 러시아어 전환 시 언어값(`ru`)을 기기 및 저장 상태에 기억합니다.
- 학교 선생님은 한국어 모드에서 기존 정확한 표기인 `기술썜`을 유지하고 러시아어 모드에서는 `Учитель технологии`로 보여줍니다. 내부 NPC ID는 변경하지 않았습니다.
- 모든 학생에게 동일한 정적 배경을 보이지 않고, 마을 경제·인구 활력·공동체 신뢰 및 실제 선택된 개선 정책을 이미지에 반영했습니다. 사회의 고령화 자체만으로 심각한 쇠퇴를 결정하지 않습니다.
- 렌더링한 이미지에 인터페이스 언어를 박아넣지 않아 언어만 바꾸어도 같은 세계의 상태가 유지됩니다.
- 엔딩 전후 비교는 마을 한 구역과 학교 교정의 **동일한 기준 촬영 위치**를 사용합니다. 이는 마을/학교 *전체* 타일맵을 한 장에 축소한 전경 이미지가 아니며, 대표적인 구역의 스냅샷입니다.
- 기존 게임의 스토리 데이터, 퀴즈 정답·문항, 맵·픽셀 이미지 에셋은 교체하지 않았습니다.

- Python `python -m pytest -q tests/test_storage.py tests/test_backend_extension.py tests/test_v4_roundtrip.py tests/test_v5_roundtrip.py`: **14개 모두 통과**.
- JavaScript 정적 구문 검사 완료. PNG 및 ZIP 유효성 검사는 최종 파일 패키징 과정에서 수행.
- 프런트엔드 구동을 위한 정적 서버는 준비했지만 **Playwright/Chromium 접속이 `ERR_BLOCKED_BY_ADMINISTRATOR`로 차단**돼서 실제 브라우저 클릭, 텍스트 레이아웃, 캡처, 태블릿 터치 동작은 검증하지 못했습니다.

- 짧은 UI 문자열부터 주요 스토리와 퀴즈 및 맵 상호작용을 번역 데이터로 연결했습니다. **일부 예외적인 자유입력 값이나 동적 에러 문구가 러시아어로 완벽하게 표시되는지는 실브라우저 확인이 필요합니다**. 사용자 자유 입력 텍스트는 원문으로 보존합니다.
