# 미래 다이어리 v4 — 한글화 및 종합 디버깅 보고서

검수 기준: 사용자가 첨부한 `서라벌여중-미래다이어리-v4-완성판.zip` 원본.

## 수정한 오류

| 발견 증상 | 원인 | 수정 파일 및 방법 |
|---|---|---|
| `나의 learning +7 · 나의 satisfaction +3` 등 영문 변수명 노출 | `story.js`의 수치 변경 함수가 영문 데이터 키를 그대로 결합 | `story.js`, 신규 `locale.js`: 개인/사회/관계 지표를 한국어로 표시하고 부호를 유지하는 공통 포맷터 적용 |
| 마을 시나리오의 효과도 영문 변수명 형태로 나올 가능성 | 지역 변화에 별도 변경 처리 함수를 사용하면서 출력 레이블을 통일하지 않음 | `story.js`: 동일한 공통 포맷터를 지역 시나리오에도 적용 |
| 이전 v4 기록에 이미 저장된 영문 수치 문자열 | 기존 기록은 문자열로 저장되어 코드를 수정해도 그대로 남음 | `locale.js` 및 `game.js`, `story.js`: 저장 데이터를 파괴적으로 변경하지 않고 다이어리 열람·결과·텍스트 내보내기 시 표시 텍스트를 한국어로 변환 |
| 활동 가방의 `developer` 등 영문 직업 코드 노출 | 직업명 표기가 `careers` 내부 ID를 직접 사용 | `game.js`/`locale.js`: 직업 코드 한글 표시 매핑 |
| `CHAPTER`, `CH`, `FUTURE DIARY`, `S` 등 영문 표제 노출 | 메인 화면의 고정 문자열이 영어 | `game.js` 및 `index.html`: 플레이어용 표제를 한국어로 변경 |
| 구글 시트 전송 대기 상황의 잘못된 상태 문구 | 서버 `sync` 값은 문자열인데 화면이 객체의 `.pending` 속성을 확인 | `game.js`: 문자열 상태 `'pending'`, `'failed'`를 올바르게 구분하여 한글 표시 |
| 교사용 대시보드에서 `age`, `choice`, `result` 같은 영문 표 머리글 및 사회 지표 키 노출 | 내부 원본 딕셔너리를 그대로 데이터프레임·JSON에 렌더링 | `app.py`: 한국어 열 이름·사회 지표 이름으로 렌더링 |
| 레거시 다이어리의 효과 필드가 배열이 아닌 경우 표시 중 오류 가능성 | 렌더러가 `r.effects.map`을 무조건 호출 | `game.js`: 배열 여부 검사 후 표시, 저장 형식 유지 |

## 재사용 및 보존

- 원본 ZIP에 들어 있던 PNG **76개 모두 바이트 단위로 동일**하며, 기존 타일맵·NPC·교실·건물 데이터를 수정하지 않았다.
- `story_v4.json`의 **32개 사건과 11개 분기 장면**, 8개 챕터 및 모든 선택의 로직은 유지했다.
- 기존 저장 상태의 ID/버전/스키마 및 SQLite/Sheets 저장 형식을 변경하지 않았다.
- 서라벌여중 교사 17명의 게임 표시명은 모두 요청한 철자 **`기술썜`**이며 변경하지 않았다.

## 검증하지 못한 항목 및 실행환경 제약

- **브라우저 실화면 조작:** 정적 HTTP 서버는 정상적으로 응답했으나, Chromium / Playwright가 로컬 테스트 URL 접속을 `ERR_BLOCKED_BY_ADMINISTRATOR`로 거부했다. 브라우저 클릭·화면 배치·실제 시각 효과·전체 스토리 UI 흐름에 대한 E2E 검증은 이 환경에서 완료하지 못했다.
- **실물 태블릿:** 실제 iPad/안드로이드 태블릿 터치, 기기 회전, 장시간 플레이를 검증하지 못했다. 기존 터치/반응형 구현은 보존했다.
- **Google Sheets 실연동:** 실제 서비스 계정과 시트 ID가 없어 라이브 시트 전송은 검증하지 못했다. 기존 Sheets 모의 객체 단위 테스트는 통과했다.
- **20분 수업 시간:** 실제 학급에서 평균 플레이 시간을 실측하지 못했다.

이 항목들은 "테스트 통과" 또는 "완료"라고 주장하지 않는다. 실제 기기와 배포 URL에서 별도 수락 검증이 필요하다.

## 배포 및 실행

원본 실행 방식 유지: Python 3.11 이상 환경에서 `pip install -r requirements.txt` 후 `streamlit run app.py`.

또는 `components/rpg_game`을 정적 웹 서버로 제공하여 게임 UI를 확인할 수 있다. `docs/V4-STORY-IMPLEMENTATION.md`에 스토리 조작 방법이 있다.
