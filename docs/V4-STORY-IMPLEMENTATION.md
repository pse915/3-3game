# 미래 다이어리 v4 — 15~65세 생애 시뮬레이션

## 실행

기존 실행 방식 유지: Python 3.11+, `pip install -r requirements.txt` 뒤 `streamlit run app.py`. 학생용 RPG 정적 화면은 개발용으로 `components/rpg_game`에서 정적 HTTP 서버를 열어 확인할 수도 있다.

첫 화면에서 캐릭터를 고르고 게임을 시작한 뒤 **📔 스토리** 버튼을 누른다. 안내 장소로 이동하면 📔 표식 NPC와 대화하여 사건을 해결할 수 있다. 키보드에서는 **Q**가 스토리 단축키다. 다음 장면 위치가 먼 경우에는 스토리 대화창에 있는 장소 이동 버튼을 이용한다. 이동·터치·길 안내·다이어리·기존 활동 메뉴는 v3와 같다.

## 스토리 구성

- 15세: 중학교 졸업, 친구, 일반고/직업계고/대안학습·직업훈련 선택
- 18세: 경로별 학교·현장 사건, 일과 공부의 갈등, 졸업 이후 결정
- 23세: 대학/취업/재탐색의 일상, 대학원/심화학습·현장학습 선택
- 31세: 점진적 만남과 관계, 결혼/비혼/동반자, 양육과 공동체 돌봄
- 41세: 책임과 변화, 경로별 가족·사업 사건, 재교육 및 지역 회의
- 51세: 자동화, 돌봄, 마을 쇠퇴 대응, 오랜 친구 재회
- 60세: 은퇴·노후 자원·건강·사회참여, 지역 재생
- 65세: 서라벌여중 재방문, 옛 교실과 15세 편지, 마을의 변화, 개인별 다이어리 회고

총 **32개 필수 사건**, **11개 조건별 대체 연출**, 사건마다 선택지 3개, 외부 지역사회 변화 실험을 수록했다. 별도 `data/story_v4.json`으로 데이터를 관리한다.

개인의 선택에 따른 직업·배움·관계·가치관 플래그는 이후 시나리오의 조건·묘사·결과 문구와 생애 엔딩에 반영한다. 타인의 행동, 인구 이동 및 경기 침체 등은 외부 사회 변화로 모델링하며, 특정 개인의 비혼/비출산 선택을 사회 쇠퇴의 직접 원인으로 처리하지 않는다.

## 마을 변화

`story.js`의 `worldTier`가 지역 경제·인구 활력·공동체 신뢰·돌봄 여건·환경·안전망을 종합해 **활기 → 변화 → 쇠퇴 → 심각한 쇠퇴** 4등급으로 구분한다. 학교·마을 렌더러는 기존 건물 에셋에 틴트·균열·잡초·빈 공간 효과를 겹쳐서 표현한다. 마을의 일반 주민 수와 대사도 등급에 따라 달라진다. 챕터 5~7에서는 지역사회 변화 가상 시나리오(협력 투자·인구 이동·경제 불황)를 각각 한 번 체험할 수 있으며, 다른 챕터의 지역 재생 선택으로 회복할 수 있다.

## 저장 및 기존 기능

기존 v3 state `version:2` 및 `life.version:1`을 유지하고 `life.story`에 v4 생애 데이터를 추가했다. 로컬 저장, JSON 백업·복원, 서버 SQLite/Google Sheets의 `state_json`을 통한 기록 구조를 유지한다. v3 저장에서 v4를 시작하면 기존 자료는 지우지 않고 생애 스토리가 새로 시작된다. v3의 기존 핵심 5개 선택과 자유 활동은 메뉴에서 별도로 계속 접근할 수 있다. 교사 17명의 게임 표시 이름과 학교 NPC 표시 이름을 요청에 따라 모두 **기술썜**으로 변경했다.

Streamlit의 교사 화면에서 v4 생애 사건 수, 65세 성찰, 사회 지표도 볼 수 있다. 단 실제 Google Sheets 서비스 계정에 대한 전송과 실물 태블릿 테스트는 별도 확인이 필요하다.

## 테스트 결과와 한계

- `node --test tests/*.test.mjs` : 24개 단위 테스트 통과. v4 스토리를 포함해 200개 결정 경로의 65세 완주 및 기존 저장 검증 테스트 추가.
- Python 서버 `validate` / SQLite `save` / `restore` : v4 32개 사건 완주 저장 예시 통과.
- 게임 본문 모듈과 Python 서버 구문 검사 통과.
- 브라우저 자동 테스트는 현재 테스트 환경이 localhost/file/data URL 탐색을 관리자 정책으로 차단해 실행하지 못했다. 실제 웹 렌더링, 교실 배치의 건축 정확성, Google Sheets 연결, 실기기 태블릿 사용성은 검증하지 않았다.

작동을 검증하지 못한 항목은 검증되었다고 표시하지 않는다. 20분 안에 모든 경로를 끝낼 수 있도록 빠른 이동을 제공하지만, 실제 학급에서의 평균 완료 시간은 실측하지 않았다.
