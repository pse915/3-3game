브라우저 시나리오에서는 검증용 인터페이스로 장소·좌표를 이동한 다음, 실제 화면의 조사·선택 버튼을 눌렀습니다. 이를 전체 맵을 터치로 걸어서 완주한 테스트로 해석하면 안 됩니다. 지도 연결 검사와 터치 이동 검사는 별도로 수행했습니다. `?test` 쿼리가 있을 때만 검증용 인터페이스가 열리며 일반 실행에는 노출되지 않습니다.

## 수정한 문제

- 바닥 픽셀의 알파값 때문에 생기던 어두운 얼룩을 불투명 저대비 질감으로 수정.
- Windows SQLite 연결이 남아 파일을 잠그던 문제를 context manager에서 명시적으로 닫도록 수정.
- 초기 맵 미리보기가 이전 기기 저장을 덮어쓰지 않도록 수정.
- 배경·NPC의 화면 밖 렌더링 제외, 프레임 상한, 5개 맵 캐시 적용.
- 교사·주민 임시 색상 변형 캐릭터를 별도 NPC PNG로 교체.
- 학교 외관 및 마을 16개 건물의 독립 원본 PNG 제작·적용.

## 성능 결과 읽기

`evidence/performance-results.json`은 Windows 데스크톱 Chrome에서 CPU 4배 제한을 적용해 60초간 이동 입력을 유지한 결과입니다. 실기기 벤치마크가 아니며, 모든 기기에서 30/60FPS를 보장하지 않습니다. 상태 위치, FPS, JS heap, 캐시 수를 15초 간격으로 기록했습니다. 프레임 간격으로 계산한 FPS는 GPU 메모리나 입력 지연을 나타내지 않습니다.

## 남은 제작 작업

1. 제공 예정 참고 이미지와 실제 실행 화면을 나란히 대조하고 에셋 재작업.
2. 실제 학교 배치도에 맞춰 방 순서·계단·출입·외관 동선을 재검증. 현재 엘리베이터 이동은 있으나 별도 계단 그래픽·동선은 충분하지 않음.
3. 건물별 실내 고유 배치와 생활 사건 확충, 큰 맵의 빈 공간 감소 및 탐험 보상 추가.
4. 독립 플레이어 외형 4종, NPC 4방향 걷기·달리기, 표정 및 생활 일정 확대.
5. 청년기·성인기·노년기의 환경 변화와 선택 후속 사건 확대. 현재 단계·자원·기록 및 일부 공원 장식만 변함.
6. 완전한 서버 복구 운영, Sheets 실제 실패/재연결 시험, 기관 인증 및 다중 반 운영 설계.
7. iPad Safari·Android 실기기, 장시간 발열·메모리·입력 끊김·주소창·화면 회전 테스트.
8. 교과서 원본 교차 검증 및 중학생 수업 관찰 후 20분 동선 조정.

성적·삶의 등급·결혼·출산 강요는 구현하지 않았습니다. 자원 수치는 모두 가상 시나리오입니다.
