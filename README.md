# 미래 다이어리 v5.3 — 퀴즈 연동·마을 폐허화 통합판

최초 응답 기록, 실제 폐허 건물·학교, 정책 회복, 같은 상태의 65세 비교 이미지를 추가했습니다. 기존 12개 필수/3개 보충 퀴즈와 8개 챕터·길찾기·한국어/러시아어를 유지합니다.

# 서라벌여중: 나의 미래 다이어리

**개정 3: 자유 생애설계 활동을 추가한 실행 가능한 수정판. 전체 지시문 인수는 부분 완료입니다.** 실제 학교 대조와 태블릿 실기기·학생 수업 검증은 남아 있습니다.

기존 80개 맵과 핵심 다섯 이야기를 유지하면서, 원하는 순서로 선택하는 25개 활동·8개 직업 작업 체험·8종 돌발 사건·8가지 미래 모습을 추가했습니다. 시간·생활자금·피로·만족·성장·안정·미래 준비·건강·관계가 변하고, 선택에 따라 후속 활동과 지역 기록이 열립니다. 이유·실천 계획과 결과는 다이어리와 교사 화면에서 확인합니다.

화면의 **활동** 버튼으로 가까운 체험과 다른 장소의 기회를 찾습니다. **메뉴**에서 지도·퀘스트·가방·꾸미기·설정·저장을 열 수 있습니다. 집에서 다음 날을 시작하면 가상 시간이 다시 채워집니다. PC에서는 B 활동, Esc 메뉴를 사용할 수 있습니다. 교실과 마을의 이름은 현재 위치 표시와 도착 안내로 확인합니다.

현재 검증 결과와 남은 요구사항은 [QA-v3](docs/QA-v3.md), 교과서 연결은 [LEARNING-v3](docs/LEARNING-v3.md), 서버·Sheets 운영은 [OPERATIONS-v3](docs/OPERATIONS-v3.md)를 먼저 읽어 주세요. 기존 QA 자료는 이전 버전 기록입니다.

신규로 작성한 Streamlit + Canvas RPG입니다. 외부 게임의 코드나 에셋을 복제하지 않았습니다. 32px 기본 타일, 32×48 플레이어 프레임, 별도 제작 PNG 아틀라스, 80개 JSON 맵, 학교 4개 층, 17개 학급 및 담임 데이터, 미래마을 16개 주요 건물, 세 장면·5회 선택과 학교 귀환 엔딩을 포함합니다.

기존 공간별 명세는 [SPACE_SPECS](docs/SPACE_SPECS.md)를 확인하세요. 기존 v2 기록은 자유 활동 상태를 덧붙여 이어갑니다. 구버전 v1 진행은 서버에 보존하지만 새 이야기로 자동 변환하지 않습니다.

## 실행

Python 3.11 이상에서 프로젝트 폴더를 연 뒤 실행합니다.

```sh
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

표시된 주소를 브라우저에서 엽니다. Google 인증 없이도 기기 저장 및 서버 SQLite 저장이 동작합니다. 이 ZIP에는 인증키와 진행 데이터베이스가 포함되지 않습니다.

프런트엔드만 확인하려면 아래 명령 후 `http://localhost:8765`를 엽니다. 이 모드에는 서버 저장과 교사 화면이 없습니다.

```sh
python -m http.server 8765 --directory components/rpg_game
```

## 플레이

- 캐릭터를 선택하고 첫 페이지를 엽니다. 바로 옆 선생님과 이야기한 뒤 교정의 다이어리를 엽니다.
- PC: 방향키/WASD, Shift 달리기, Enter/Space 상호작용, M 지도, J 다이어리.
- 터치: 방향패드 길게 누르기, 달리기 전환, 오른손 이야기 버튼. 입력은 Pointer ID별로 관리합니다.
- **메뉴 → 지도**에서 학교 층과 주요 사건 장소로 빠르게 이동할 수 있습니다. 개별 교실에는 복도의 문으로 들어갑니다.
- 단서 반복 조사는 없습니다. 일과 집, 하루, 돌봄, 공동 준비, 노후 준비를 자연스럽게 선택합니다. 시설·주민·대사와 기록이 달라집니다.
- 다섯 선택 후 변화한 학교로 돌아가 다이어리에 생각을 적으면 엔딩이 열립니다. 길 안내는 처음과 이어하기 모두 기본으로 켜지며 문·층 이동 후 자동 갱신됩니다.
- 모든 학급을 방문할 필요는 없습니다. 결혼·출산이나 특정 직업은 진행 조건이 아닙니다.
- **다이어리**에서 진행 백업 JSON과 글 TXT를 내려받을 수 있습니다. 백업에는 복원 토큰이 들어 있으므로 개인 기록처럼 보관합니다.

## 저장 및 Google Sheets

1. `.streamlit/secrets.example.toml`을 배포 서버의 `.streamlit/secrets.toml`로 복사합니다.
2. Google Sheets API가 활성화된 서비스 계정을 준비하고, 대상 시트에 해당 계정의 편집 권한을 부여합니다.
3. `google_sheet_id`, `gcp_service_account`, 교사용 `teacher_password`를 서버에 설정합니다. 키를 채팅이나 클라이언트 코드에 넣지 않습니다.
4. `checkpoints` 워크시트는 필요하면 생성됩니다. 구조는 `id, token_hash, revision, payload`입니다.
5. 한 개의 서버 프로세스에서 SQLite와 Sheets를 함께 운영합니다. 다중 서버 쓰기 및 분산 동시성은 이 버전의 범위가 아닙니다.

기기에는 약 7초마다 위치를 저장하고, 중요 선택·맵 이동 시 서버 체크포인트를 보냅니다. SQLite outbox는 실패한 Sheets 전송을 보관합니다. 클라이언트의 30초 주기 재전송 시 지수 백오프에 맞춰 다시 시도합니다. 기기 저장은 서버 실패와 독립적입니다. 서버를 종료한 동안 outbox가 스스로 전송되지는 않습니다.

서버는 학생 ID뿐 아니라 복원 토큰을 검증합니다. 교사 조회에는 비밀번호가 필요합니다. 학교 운영을 위한 기관 SSO·계정 관리·다중 교실 권한 분리는 추가 작업입니다. Streamlit Community Cloud의 임시 파일시스템을 영구 저장소로 간주하면 안 됩니다. 서버 디스크가 사라지면 Sheets와 개인 백업으로 복원해야 합니다.

## 교사용 화면

왼쪽 사이드바에서 **교사용 대시보드**를 선택하고 설정한 비밀번호를 입력합니다. 익명 참여 현황, 경험한 사건·개념, 선택 분포, 성찰, 완료 여부와 활동 시간을 표시합니다. 삶의 방식에 점수나 등급을 붙이지 않습니다.

## 맵 및 성능 구조

| 공간 | 크기 |
|---|---|
| 교정 | 128×128타일 |
| 학교 1~4층 | 각각 96×96타일 |
| 교실·특별실·마을 실내 | 각각 32×32타일 |
| 미래마을 | 256×256타일 |

맵은 별도 JSON으로 지연 로딩하며 최근 5개만 캐시합니다. 보이는 타일과 오브젝트만 그립니다. PNG 아틀라스는 한 번 읽습니다. 화면 버퍼는 CSS 화면 기준 1배 또는 1/2 크기로 제한하고, 높은 DPR로 다시 곱하지 않습니다. 렌더링은 약 60Hz로 제한합니다. 이동과 카메라는 시간 차이로 계산하며, 탭이 숨겨질 때 입력을 초기화합니다. 경로 안내는 현재 맵의 충돌 격자 BFS를 사용합니다. 맵 사이에는 연결 그래프를 따라 다음 출입문으로 안내합니다. 지도 빠른 이동도 사용할 수 있습니다.

## 소스 구조

`app.py`: 실행·서버 통신·교사 화면. `server/`: 인증된 저장, SQLite outbox, Sheets 어댑터. `components/rpg_game/`: Canvas 렌더러·입력·UI. `data/`: 맵·교사·사건. `assets/`: 실제 적용한 PNG와 생성 원본. `build_world.py`: 결정적 맵·타일 생성. `tools/`: 에셋 정규화. `tests/`: 상태·저장·지도 검사. `docs/`: 품질 판정, 검증 결과, 제작 출처.

## 최종 완료를 막는 사항

참고 이미지 2장과 실제 학교 사진·교실배치도는 작업 환경에서 확인되지 않았습니다. 그래픽과 학교 좌표는 원본 대조 전입니다. 교과서102-103페이지.docx 본문은 읽고 생애체험 선택에 반영했습니다. 학교 공간 순서는 임시이며 실제 학교 재현도가 확인되지 않았습니다.

학교와 마을의 공간 밀도, 교실별 개성, NPC 이동·방향 애니메이션, 플레이어 외형 4종의 독립 디자인, 표정 세트, 독립 UI·장식의 전체 목록, 장기 플레이 및 수업 시간 검증은 추가 제작·개선이 필요합니다. 현재 플레이어 선택 4종은 색상 변형입니다. 모든 NPC가 4방향 애니메이션을 가진 것은 아닙니다. 큰 맵의 면적 자체가 충분한 탐험 콘텐츠를 보장하지 않습니다.

실제 iPad·Android 태블릿, Google Sheets 실연결, 18~20분 학생 수업, 배포 환경 검증은 미완료입니다. **요청된 상용 수준의 최종 품질을 통과했다고 보고하지 않습니다.**

## v5.2 — 학생용 메인 퀘스트 길 안내

- 게임 시작 시 **스토리 집중 모드**가 기본이며, 상단의 `★ 현재 목표` 안내가 다음 이야기 장소와 NPC를 보여줍니다.
- NPC 또는 다음 지도 통로 위의 **노란 별표(★)**를 따라가거나 **★ 길 안내**를 눌러 이동 경로를 확인할 수 있습니다.
- **지도 보기**에서 목표 장소와 다음 출입구를 확인하고, 길찾기가 어렵다면 안전한 빠른 이동 기능을 이용할 수 있습니다.
